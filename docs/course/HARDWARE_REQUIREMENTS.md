# Hardware & Equipment Requirements

**Course:** ATmega328P Bare-Metal Microcontrollers  
**Institution:** TecNM / Instituto Tecnológico Superior de Jerez  

---

## 1. Per Student / Team Equipment Kit

| Item | Quantity | Description / Specification |
| :--- | :---: | :--- |
| **Microcontroller** | 1x | ATmega328P-PU (DIP-28 package) + 28-pin DIP socket |
| **Breadboard** | 1x | Standard 830-point solderless breadboard |
| **Crystal Oscillator** | 1x | 16.000 MHz HC-49S Quartz Crystal |
| **Capacitors** | 2x / 1x | 22 pF ceramic (crystal load), 100 nF ceramic (decoupling), 10 µF electrolytic |
| **Resistors** | Kit | 330 Ω (LED limiters), 4.7 kΩ (I2C pull-ups), 10 kΩ (Reset/Button pull-ups) |
| **LEDs & Push Buttons** | 5x / 4x | 5mm LEDs (various colors), 4-pin tactile push buttons |
| **Analog Input** | 1x | 10 kΩ linear potentiometer |
| **USB-UART Adapter** | 1x | USB-to-UART TTL converter (FT232RL, CP2102, or CH340G) |
| **ISP Programmer** | 1x | USBasp ISP programmer with 10-pin to 6-pin ISP cable adapter |
| **Power Module** | 1x | 5V / 3.3V Breadboard power supply module or 5V DC regulated source |
| **Jumper Wires** | 1x Set | Male-to-Male and Male-to-Female jumper wire kit |

---

## 2. Shared Laboratory Equipment

| Item | Description / Specification | Purpose |
| :--- | :--- | :--- |
| **USB Logic Analyzer** | 8-Channel, 24 MHz Saleae-compatible USB Logic Analyzer | Decoding UART, SPI, and I²C bus signals in real time |
| **Digital Oscilloscope** | Dual-channel 50 MHz+ benchtop oscilloscope | Measuring PWM duty cycles, rise times, and interrupt latency |
| **Benchtop Power Supply** | Regulated 0–30V / 0–3A DC Power Supply | Supplying clean power for high-current loads |

---

## 3. Optional Peripheral Accessories (For Modules 08–12)

* **Display:** 16x2 Character LCD with PCF8574 I²C backpack.
* **External Memory:** 24LC256 I²C EEPROM or SPI EEPROM breakout.
* **RTC Module:** DS1307 or DS3231 I²C Real-Time Clock module.
* **Actuators:** SG90 Micro Servo motor, 5V passive buzzer.
