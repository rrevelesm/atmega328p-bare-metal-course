## Dual License Breakdown

The repository utilizes a dual-licensing scheme to distinguish between software source code and educational/course material:

### 1. Software Code & Build Infrastructure
All C source code (`.c`), header files (`.h`), Makefiles, build scripts, VS Code task configurations, and CI workflows are distributed under the **MIT License**.

* **License File:** [LICENSE-CODE](../../LICENSE-CODE)
* **Summary:** Open-source software permission allowing commercial and academic use, modification, and redistribution with copyright attribution.

### 2. Educational Material & Documentation
All laboratory practice guides, pedagogical architecture specifications, learning outcome documents, diagrams, and markdown course materials are distributed under the **Creative Commons Attribution 4.0 International License (CC BY 4.0)**.

* **License File:** [LICENSE-DOCS](../../LICENSE-DOCS)
* **Summary:** Open educational resource license allowing sharing and adaptation provided appropriate attribution is given to the author and institution.
